# Architecture Decision Records

Numbered, append-only records of non-obvious technical decisions for the
web application — what was decided, what alternatives were rejected and
why, and what it costs going forward. This is a decision *history*, not
current-state reference material (that's [`docs/architecture.md`](../architecture.md),
[`docs/database.md`](../database.md), etc. — see the
[`README.md`](../../README.md)'s Documentation table); a decision recorded
here stays as-written even after a later record supersedes it.

Records are created by the `decision-record` skill — see that skill
for the workflow and template.
