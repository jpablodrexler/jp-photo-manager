# BUG-005 — `GET /api/assets/{id}/stream` serves `asset.getFullPath()` with no root check

- **Steps to reproduce:** (inferred from code reading; not yet reproduced at runtime)
  1. Get a path outside the catalog roots into an `assets` row (for example through BUG-004's folder paths).
  2. `GET /api/assets/{id}/stream`.
- **Expected:** the file is served only if its real path is inside a configured root.
- **Actual:** `MediaController.streamAsset` builds a `FileSystemResource` from `asset.getFullPath()` with no containment check; it is safe only while every stored path is trusted.
- **Environment:** both — independent of the deployment.
- **Schema change:** no
- **Notes:** `infrastructure/web/controller/MediaController.java` (`streamAsset`). Add the check at read time. Same cause as BUG-004. Source: security review 2026-10-15, §2.1.
