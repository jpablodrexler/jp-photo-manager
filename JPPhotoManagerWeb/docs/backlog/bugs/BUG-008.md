# BUG-008 — Album date filters are saved one day off depending on the time zone

- **Steps to reproduce:**
  1. In a time zone ahead of UTC, create or edit a smart album with a `dateFrom` or `dateTo`.
  2. Reopen the album.
- **Expected:** the saved date equals the picked day.
- **Actual:** `albums.component.ts:118` and `edit-album-filter-dialog.component.ts:89-90` use `date.toISOString().split('T')[0]`, which converts to UTC and shifts the day; the dialog's `new Date('YYYY-MM-DD')` parses as UTC and can shift it the other way.
- **Environment:** both — depends on the browser's time zone.
- **Schema change:** no
- **Notes:** format with the local year/month/day. A comment in `edit-album-filter-dialog.component.cy.ts` already mentions the `toISOString` sensitivity. Source: code review 2026-10-15.
