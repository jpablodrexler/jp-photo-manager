# BUG-006 — Editing an album's filter erases its description

- **Steps to reproduce:**
  1. Open a smart album that has a description.
  2. Use the edit-filter dialog and save.
  3. Reopen the album.
- **Expected:** the description is kept.
- **Actual:** `album-detail.component.ts` sends `updateAlbum({name, filterJson})` without `description`, and `UpdateAlbumUseCaseImpl` unconditionally does `album.setDescription(description)`, so it becomes `null`.
- **Environment:** both — frontend payload plus backend PUT semantics.
- **Schema change:** no
- **Notes:** `frontend/src/app/features/albums/album-detail/album-detail.component.ts:75`, `backend/.../application/usecase/album/UpdateAlbumUseCaseImpl.java:29`. Send the current description, or make the PUT partial. Source: code review 2026-10-15.
